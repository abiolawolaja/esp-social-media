# ESP email templates

House templates for EventSpacePro emails. Copy one, change only the copy and images, keep the layout.

| File | Use for |
|---|---|
| `templates/newsletter.html` | Monthly / regular Mailchimp newsletter (hero, button, tip + story boxes) |
| `templates/product-update.html` | Feature launches and product news (New in ESP band, 3 steps, Also new) |
| `templates/gmail-signature-and-reply.html` | Gmail signature + everyday reply layout |
| `esp-logo-email.png` | Logo used in the email header (public link below) |

Logo link: https://raw.githubusercontent.com/abiolawolaja/esp-social-media/main/email/esp-logo-email.png

To load a template into Mailchimp: Templates → Create template → Code your own → Paste in code.
